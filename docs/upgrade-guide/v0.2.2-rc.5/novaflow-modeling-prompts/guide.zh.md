# 跨模式共享提示词预设

[English](guide.md) | 中文

## 变更

NovaFlow 桌面端从预设列表移除建模模式。已有建模会话和默认模式设定按标准模式运行。所有模式都可以使用相同的企业工作提示词。内置库随桌面版本更新，自定义库保存在当前用户配置中。

## 迁移

1. 打开已有建模会话，即可按标准模式继续。如果自定义覆盖配置引用了 `novaflow-modeling`，请改为 `standard`。
2. 在任意模式的新会话中打开「CAD 与建模」。旧版中新增或改写的提示词可在「设置 → 提示词预设」找到。

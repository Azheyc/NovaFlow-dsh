# NovaFlow 提示词预设

适用于 NovaFlow 和 DeepSeek Harness `dsh-v0.2.2-rc.3`。在新会话首页选择类型，悬停预览，点击填入完整提示词，再编辑或发送。已有草稿时会先确认替换。

NovaFlow 首页的分类和推荐随模式选择切换，选定工作区后即可填入提示词。没有独立提示词库的模式沿用标准模式的预设。

在「设置 → 提示词预设」选择模式和分类，点选列表中的提示词即可编辑标题和正文。「管理分类」可重命名、排序或删除分类。将提示词加入首页推荐后，可在「首页推荐」调整顺序或移除；四个位置已满时可直接选择替换项。

点「保存修改」一次保存所有模式的草稿，并更新首页。切换模式或设置页可继续编辑当前窗口中的草稿，重启窗口前需要保存。「放弃修改」会重新载入当前 profile 最近保存的配置。

NovaFlow 随包预装。独立安装时，在目标 Host 使用 `dsh plugin --profile web add <插件压缩包的绝对路径.tgz>`，然后重启。通过插件管理页面停用或卸载。

# NovaFlow 提示词预设

[English](README.md) | 中文

所有会话模式共用一套预设。新会话首页可按工作类别选择任务，悬停预览，点击后把提示词填入草稿。已有草稿时会先确认替换。

新会话首页提供办公文档（Excel、Word、PPT）、数据调研、内容平台、销售与客户、采购与合同、项目管理、人事行政、CAD 与建模八类内置工作模板。维护者编辑 `catalog.js` 后随客户端发布，用户升级即可获得新版。

「设置 → 提示词预设」直接打开自定义预设编辑器。添加提示词后填写标题和正文，点击「保存修改」。也可管理分类、调整顺序。已有首页推荐继续显示，删除对应提示词后由内置推荐补齐。

自定义内容单独保存在当前 profile 的 `.novaflow-prompt-presets.json`。旧版按模式保存的新增或改写提示词会进入共享自定义库，首次保存时写入新版格式。

# NovaFlow 自媒体工作台

[English](README.md) | 中文

从 NovaFlow 客户端侧栏打开「自媒体工作台」，首次直接进入灵感页。插件默认使用客户端数据目录下的 `media-desk/files`。可在工作台设置中更换或恢复默认位置，旧项目和素材继续从原目录读取。外置盘需保持挂载。

## 无限画布

点击顶部独立的「无限画布」按钮，直接打开上次使用的画布。没有画布时自动创建「未命名」。用底部的「添加节点」放入文本、图片、视频或生成节点。节点平时显示预览，点击卡片展开编辑器，点击空白处或按 Esc 收起。文本支持 Markdown。将右侧的输出点拖到另一个节点左侧的输入点即可连线，也可以反向拖动。图片接入视频生成节点时默认用作参考图。在节点的「生成方式」中选过「首帧」或「多图参考」后，后续自动连线会沿用该选择。节点当前的生成方式、已有连线和模型支持的用途优先。生成节点使用 NovaFlow 模型设置里选中的模型及其分组，点编辑器的生成按钮提交任务，用「查看状态」查询原任务。

图片生成提供 1K 和 2K，默认 2K。分辨率按长边换算，提示词中的 4K 请求按相同比例生成 2K。视频支持文生、首帧和多图参考，实际参数取决于所选模型。右侧助手使用该画布专属的 DSH 会话，能读取当前技能、编辑节点、连接参考图、生成媒体和查询任务。

按住 Shift 拖动空白区域可框选。Ctrl 或 ⌘ 配合 C、V、Z、Shift+Z、F、G 分别复制、粘贴、撤销、重做、查找和分组。Shift+Ctrl/⌘+G 解组。画布支持小地图、网格吸附、自动布局和视口恢复。

## 文件保存

上传文件在「素材」，生成结果在「生成/图片」和「生成/视频」，成稿导出在「成稿」，画布文档在「画布」。已有的灵感、设置、DSH 会话、旧附件继续使用原有存储。删除画布时会显示可选清理的独占文件，共享文件保留。

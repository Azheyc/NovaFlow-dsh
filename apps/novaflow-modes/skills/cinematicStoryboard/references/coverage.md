# 自动分镜、多机位覆盖与场面调度

<a id="k00"></a>
## K00 读取范围与位置

新建或细化预览/完整稿时，段内只要有对白、倾听、交接、两人以上在场或生成段界，就读K01—K08；写法拿不准时看K09的简例。场面配方库与完整改写示例只在至臻完美版提供。忠实提取已有稿件不重新覆盖。

本文件衔接[story S4](story.md#s4)、[camera C01/C03/C07](camera.md#c01)、[acting](acting.md)和[space](space.md)：story定观众此刻要看什么，这里定用几种视点、在哪里切、画面里每个人在演什么；计时仍以[timing](timing.md)为准。内部完成判断，执行稿只写最终镜头，不输出覆盖分析。

**拆镜不加时**：覆盖是把剧情已经定好的同一段时间分给不同视点，不是在原时间上加镜头。按本文件拆镜后，全片T、各段D、台词语速和必要动作都不变；反应镜、插入镜、空镜只能占用本来就在进行的时间（说话者仍在说、动作仍在做、原稿本有的等待），不能为它们另加停顿或拖尾。这和timing T3的反注水规则同时成立：注水是加时间，覆盖是重新分配时间。

<a id="k01"></a>
## K01 单视点承载上限：长对白必须换视点

一个画面里一个人持续说话，正是AI视频模型最弱的地方：口型会漂、表情会僵、手势会重复，观众通常5秒左右就收不到新信息。所以对白镜按单视点承载量复核，不能因为“原镜头还看得清”就一直不切。

- **复核线**：同一机位、同一景别、同一主体持续说话，紧凑档约4—5秒、标准档约5—7秒、舒缓档约7—9秒。到线时在本句的语义块边界换视点。语义块边界包括条件、转折、加码、承诺、点名、重音落点；找不到合法边界就延到下一处停顿，不劈开词语。
- **合格的换视点**：切到听者反应，说话者在画外继续说；换说话者的另一尺度或角度（中近景→近景、侧脸、特写）；过肩镜互换主次；插入说话者的手部或相关物件；第三人的旁观视角；镜内有动机地重构画面（推到新景别并停稳、焦点转到听者、人物走位形成新构图）。镜内重构算一次换视点，从头到尾极缓慢的推近不算。
- **豁免只有三种**：①用户锁定一镜到底或固定拍法；②原稿就是要观众盯住一个人的独角戏（长篇自白、临终遗言、审讯招供），这种情况镜内仍要有至少一次可见的表演阶段变化，或焦点、尺度变化；③说话者同时在做有观看价值的连续动作（边走边说穿过院子、边包扎边交代）。采用豁免时内部要能说出是哪一种。
- **长台词必须落到听者**：同一人连续说两个以上语义块时，默认至少给听者一次画面，让观众看到这些话落在谁身上、对方接没接住。
- **不退回机械切法**：切点由语义块和说话权决定，一个镜头可以承载几句短话。两三秒就换一次说话权的快问快答，优先用同框或过肩镜承接来回，不是一句一镜，也不是轮流点名。

## K02 对白场的编排方法

先在内部把对白场拆成回合：一个回合从一方发起（要求、质问、示好、施压、揭露）开始，到另一方接招（接受、反击、回避、沉默）为止。每个回合定一个主视点方案，回合之间换。

1. **建立**：同场第一组对白的第一个镜头，让观众知道谁在、谁对着谁、中间隔着什么，通常用带前景的双人或多人关系镜。空间已经建立的续段可以直接从单人或局部开始。
2. **推进**：常规回合用过肩正反打或斜侧单人。两边景别可以不对称：压力更大或更占主动的一方可以更近。
3. **重话落地**：一句话里最重的词（价码、期限、真相、威胁、告白）落下时，画面给最需要被看见的那张脸，通常是听者；如果说话者的决心本身就是信息，就给说话者更近的景别。重话落地后约0.3—1秒的承受反应在原镜头内读完，不另加时间。
4. **说话权转移**：换人说话的前后是天然切点。同一份生成输入里可以用声音先行（画面还在听者身上，新说话者的声音先进来）或声音拖后（画面已经切到新说话者，上一句的尾音还在），让剪接不像轮流点名。跨独立输入的声音处理按[audio AU04](audio.md#au04)。
5. **呼吸点**：回合之间原稿就有沉默、看物、走动时，用插入（手、物件、门口）或空镜（已有的环境）承担，不新编事件。
6. **回到关系**：关系发生变化后（翻脸、和解、有人离席），回一次能同时看到双方的镜头，交代新的距离。

听者反应镜的写法：`[听者]近景，[说话者]在画外继续说：“……”；“[关键词]”落下时，[听者具体可见的变化]`。说话者此时不在画面里也一直在说，听者不动嘴。一段长台词里，反应镜合计占三分之一到一半的时长比较常见，具体看谁的变化更值得看。

<a id="k03"></a>
## K03 覆盖镜型：何时用、怎么写、风险在哪

| 镜型 | 用在 | 写法要点 | 风险与限制 |
| --- | --- | --- | --- |
| 关系镜（双人或多人同框） | 建立空间、距离变化、几人同时反应 | 谁在画面哪侧、谁靠近镜头谁远离镜头、中间隔着什么 | 人多时脸小，关键表情不要只放在这里 |
| 过肩镜 | 对白推进、施压、窥视 | 谁的哪侧肩在前景，虚实如何，大约占画边多少，焦点在谁脸上 | 前景的肩不能挡住对方的眼和嘴；前景人物不能突然开口 |
| 斜侧单人中近景 | 常规说话、倾听 | 脸朝画面哪侧、视线落在哪、背景是什么 | 连续几镜同角度同尺度，看起来就是同一个镜头 |
| 近景、特写 | 态度变化、重话落地 | 起始状态、触发词、可见变化 | 特写用多了会失去分量；说话时口型要清楚 |
| 侧脸、轮廓 | 克制、回避、思索、对峙中的压迫 | 哪一侧受光、轮廓光从哪来、视线朝哪 | 侧脸读不清眼神细节，变化改写下颌、喉结、鼻翼、睫毛 |
| 嘴部或眼部大特写 | 承诺、威胁、咬字的落点；或不说话时的抿唇、咬牙 | 约0.8—1.5秒，只承担一个词或一个动作 | 说话时拍嘴部大特写最容易暴露口型错误，一段最多一两次；放在不发声的间隙更稳 |
| 手部或物件插入 | 说到钱、证据、武器、信物；遮住口型风险 | 谁的手、在做什么、物件当前状态 | 只用已有物件；说话者在画外继续说 |
| 听者视角（POV） | 让观众站到听者的位置被说 | 机位高度与距离；说话者看向镜头旁边，不看镜头 | 直视镜头要用户授权或原稿有主观设计 |
| 旁观者过肩、第三人视角 | 多人场面、权力关系、偷听 | 第三人哪个部位在前景，两个主角在后方哪里 | 旁观者是否知情按原稿 |
| 空镜、环境插入 | 回合之间换气、交代时间和处境 | 只拍已有环境或已有声源 | 不能承担必须看到的反应或动作 |
| 高位、低位关系镜 | 上下位、跪坐站、压迫 | 机位高度和人物高度的关系 | 要有真实可放的高点或低位 |

镜型有职责才用，不设每段每种至少一次的配额。但同一段里连续三个镜头同主体、同尺度、同角度，就等于没有覆盖，必须改。

**空镜与非人物插入先过三问**：它承载什么剧情或情绪？换成人物反应会不会更好？删掉影响理解吗？答不上来就删。长对白的切镜以听者反应、说话者动作和关系镜为主，空镜和物件插入只作点缀，大致不超过切镜的三成；相邻两个非人物镜头不重复信息。

<a id="k04"></a>
## K04 段内镜数与镜长的合理区间

下面是复核线，不是要凑的目标，也不改变T。落在区间外时，要能说出原稿或镜头职责上的原因。

| 镜头类型 | 常见镜长 |
| --- | --- |
| 建立镜、关系镜 | 约2—4秒 |
| 对白主镜（单人或过肩） | 约2—6秒；超过K01复核线要有豁免依据 |
| 听者反应镜 | 约1—3秒 |
| 插入、局部大特写 | 约0.8—2秒 |
| 动作接触镜 | 约0.8—3秒 |
| 空镜、呼吸点 | 约1.5—3秒（要有职责） |

| 段长 | 对白为主 | 动作为主 | 抒情、等待为主 |
| --- | --- | --- | --- |
| 约10秒 | 2—4镜 | 3—6镜 | 1—3镜 |
| 约15秒 | 3—6镜 | 5—8镜 | 2—4镜 |
| 约20秒 | 4—7镜 | 6—10镜 | 3—5镜 |
| 约30秒 | 6—10镜 | 8—14镜 | 4—7镜 |

单次生成里镜头太多，模型容易吞掉切点、混淆人物。一份输入的镜数接近上沿时，每镜开头都重新点明主体和机位，不写“切回”。镜长不平均分配：重话、揭示多给，过渡和呼吸少给。

<a id="k05"></a>
## K05 施动与承受：两个人同时在演

每一个指向别人的动作或台词（骂、逼、求、递、推、宣布、示好、嘲笑），内部同时排两条线：施动者做了什么，承受者怎么接。两条线都要落到能看见的行为，不能只写一边。完整写法和反应库见[acting A10](acting.md#a10)。

- **承受者的反应类型**按性格、处境和当下目标选：承受（收下颌、垂眼、肩往里扣、手上的动作停住）、顶回（抬眼直视、上身前压、嘴角绷紧）、回避（视线移开、身体半转、手去找东西）、冻结（呼吸停一拍、眨眼变少、手停在半空）、讨好或化解（陪笑、点头、往前凑半步）。同一场里，施压升级时反应也要推进，不能一个低头用到底。
- **时机**：足够信息到达时开始，通常在关键词落下的瞬间或之后约0.2—0.5秒；不在对方开口前就反应，也不等整句说完再统一反应。
- **画外承接**：承受者在画外时，状态仍在累积；被骂了三句，再回到他时不能是没听见一样的平静脸。
- **施动者也在接收反馈**：对方顶回时加码或停顿，对方示弱时收势或乘胜追击，前提是原稿允许。

<a id="k06"></a>
## K06 在场配角与群演：每个人都是活的，但不抢戏

只处理原稿里已有的配角、旁观者、龙套和人群，不为了热闹加人。

1. **分层**：在场的非主角分三层。关注层：离事件近、知情、和结果有利害，会有清楚的反应。旁观层：看得见听得见但与己无关，反应小、晚、短。生活层：离得远或不知情，继续做自己的事。
2. **差异化**：同一层里不复制同一个表情和动作。三人以上时，同一种反应最多约三分之一的人共用。差异来自立场（护主的、幸灾乐祸的、怕被牵连的）、性格、手上的活和距离。人多时分成2—4组，每组写一个具体行为，不必逐人罗列；五人以内逐人写锚位和行为。
3. **时差**：突然的巨响可以全场同时惊动；需要听懂的信息按距离和知情先后扩散，近的先、远的后，前后相差约0.3—1秒，不整齐划一。
4. **分寸**：群演的反应幅度一般小于主角；不看镜头；主角关键表情出现时不做大动作抢视线；不同步起立、同步转头、同步鼓掌。原稿或用户要求统一动作时例外（军阵、仪仗、齐声应答、舞蹈），这时写明“统一动作”。
5. **连续**：群演的位置和状态也记进状态账。上一镜跪着的宫女，回到宽景时仍然跪着；刚被骂的随从低着头，下一镜不能抬头在笑。

<a id="k07"></a>
## K07 站位锁与纵深三层

**站位锁**：多人场在[space S02](space.md#s02)的蓝图里，给每个在场者定好“锚位＋姿态＋朝向＋纵深层＋主次”，写进【场景布局】的人物站位句（规则见[space S08](space.md#s08)）。之后每一镜都从这张图推出当前投影：谁在画面哪侧、谁靠近镜头谁远离镜头、谁挡住了谁。原稿没有走位，人物就不换锚位；主角和配角的前后关系、高低关系（坐、站、跪、台阶上下）全场保持一致；回到宽景时，人数和位置与上一次相同。

**纵深三层**：除纯插入镜和空镜外，每镜默认按“前景—主体—后景”构图，至少两层清楚，能建三层就建三层。
- **前景**：场景里真实存在、靠近镜头的东西，比如对方的肩背、扶手、桌角、器物、门框、帘幕、栏杆、烛台、人群的后脑。前景虚化、偏在画边，不挡主体的眼、嘴、手和关键物件。换机位就换前景，每镜不必是同一件。
- **主体**：本镜要读的表演或动作，焦点在这里。
- **后景**：能认出来的场景结构或地标（墙、窗、柱、门、远处的人），比主体虚一些但能看出是哪里，帮观众记住空间。

例：皇帝坐在龙椅上说话。前景是靠近镜头、虚化的龙椅扶手和皇帝搭在上面的手；主体是皇帝胸口以上，脸在焦点上；后景是殿后的屏风、墙面和两侧的柱子，略虚。下一镜换到阶下的大臣，前景可以换成另一名大臣的肩背，后景换成殿门方向透进来的光。

前景只用场景里已有的东西或在场者的身体。实在没有可用的前景，就用主体—后景两层构图，不为凑前景新增陈设、道具或路人；大特写、开阔天空、空旷场地常常没有前景，这是正常的。

**宽紧两档**：中景及更宽的镜头要数人头，在场且应可见的人全部按站位出现，每人写位置和正在做的事；中近景及更紧的镜头只写清主体，背景的人虚化即可，回到宽景时恢复。三人以上的画面写明视觉中心是谁，其余是衬托层；视觉中心同时是画面最亮或反差最强的地方（见[lighting L06](lighting.md#l06)）。

## K08 生成段界：机位一定要变

AI视频单次生成一般在15秒或30秒以内。多段拼接时，如果用首尾帧硬接，接缝处光线、手的位置、衣褶、表情的细微错位会被一眼看出来。所以默认这样处理：

1. **上段最后一镜和下段第一镜不用同一机位**。至少同时满足两项：机位角度在轴线同侧内明显改变（约30°以上，或换到另一个人的视点）；景别跨一档以上；主体改变（说话者↔听者、人↔物、单人↔关系镜）。同一机位只换景别不算。
2. **段界放在好切的地方**：优先放在说话权转移、一个回合结束、反应落定、动作完成、视线指向新对象的地方。段界前后最好是一个人切到另一个人，或一个人切到另一种尺度。
3. **不依赖首尾帧硬接**：下段首帧不是上段尾帧的复制，而是另一个视点下的同一时刻或紧接的时刻。人物位置、持物、伤势、情绪余势、光线都在新视点下重新写全。用户要求用首尾帧接续时，提醒接缝风险，并建议把接缝放在动作中途，用动作切掩盖。
4. **轴线不越**：段界换机位仍在关系轴同一侧，越轴按[space S05](space.md#s05)。
5. **豁免**：用户明确锁定一镜到底、同构接续或同机位延续时照办，在块外说明接缝风险。

<a id="k09"></a>
## K09 简例：20秒单镜独白改成多视点

原稿把罗福玉约20秒的一整段条件陈述放在一个“固定中近景”里，陈放和梁文杰都在画外。按语义块（提议、时限、保障、表彰、个人加码）在原来的20秒内重分：过肩中近景拍罗福玉说提议 → 陈放近景，罗福玉在画外继续说时限，“六点之前”落下时陈放眉心收紧 → 三人斜侧关系镜，罗福玉说保障时朝梁文杰偏头，梁文杰站直 → 罗福玉近景说表彰，“表彰”落重音 → 陈放近景听完“两千块钱当劳务费用”，抿住嘴唇没有接话，切到抢话的梁文杰。原话不改、总长不变、站位不变。

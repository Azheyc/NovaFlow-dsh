# 场景光照与人物布光

<a id="l00"></a>
## L00 读取范围

本页把[camera C05](camera.md#c05)“光有来处、同场固定世界光源”和[C09](camera.md#c09)的每镜受光句式落成整场光照方案。完整稿读L01—L09；新建预览只在内部用L01—L05规划受光，不写进预览；只改光影时读对应节。光源只取原稿、参考或场景里本来会有的东西，不补带剧情意义的新光源。

<a id="l01"></a>
## L01 场景光照表

每场排镜前在内部定好五项，之后每个机位的受光都从它推出：
1. 时段与天气：按原稿；没写就按剧情最自然的时段，不默认黄昏和逆光。
2. 具名光源：挂在地标上（“柜台上方的日光灯管”“龙椅背后的高窗”），写颜色倾向（偏暖、中性、偏冷、偏绿）和软硬。
3. 主要人物在主视方向下哪一侧受光、暗面朝哪。
4. 光比档（柔和／明确／强烈），同场一致。
5. 光变节点：有没有、从哪一镜生效。

光照表写进【全局光影画风】的“场景光照”一行；逐镜只写和它不同的地方。

<a id="l02"></a>
## L02 时段与常见光源速查

| 时段/光源 | 方向与光质 | 颜色倾向 | 提醒 |
| --- | --- | --- | --- |
| 清晨 | 低、柔 | 偏暖 | 长影 |
| 上午、下午 | 中高、较硬 | 中性偏白 | 常规日戏 |
| 正午 | 头顶、硬 | 中性偏白 | 眼窝暗，关键眼神戏借地面或桌面反光 |
| 黄昏 | 极低、暖 | 暖橙到金 | 长影、逆光勾边；原稿是这个时段才用 |
| 阴天、雨天 | 柔、几乎无影 | 偏冷 | 低反差；雨天湿地面有倒影 |
| 月夜 | 高处 | 偏冷蓝 | 亮区靠场景里已有的窗、灯、火 |
| 烛火、炉火、白炽灯 | 点光源、衰减快 | 暖橙 | 火光摇曳，离光一步就暗很多 |
| 日光灯 | 顶部、平 | 偏白或偏绿 | 冷漠、办公室、医院 |
| 屏幕 | 近、前方或下方 | 偏冷蓝 | 只亮脸的一部分，随内容闪 |
| 霓虹 | 侧面、彩色 | 随灯色 | 彩色溢光、湿地面反射 |

交付稿写成看得见的颜色，不写开尔文数、色码或胶片型号。

<a id="l03"></a>
## L03 人物布光

在[C09](camera.md#c09)受光方向的基础上补三种常用写法：
- **伦勃朗光**：前侧光照脸时，暗面脸颊出现一块倒三角光斑，立体、有分量，正剧常用。
- **宽面光与窄面光**：人物侧脸对镜头时，照亮靠近镜头的半边是宽面光（显亮、坦白），照亮远离镜头的半边是窄面光（显瘦、立体、更有戏）；对峙、悬疑优先窄面光。
- **蝴蝶光**：主光在正前上方，鼻下有蝶形小阴影，端庄好看；需要场景里真有正前上方的光源。

<a id="l04"></a>
## L04 光比与补光来源

光比写成柔和（暗面接近亮面）／明确（暗面清楚但明显暗）／强烈（暗面大半沉进阴影）／剪影，需要时补约1:2、1:4、1:8。暗面能看清，一定写出托住它的东西：白墙、地面、桌面、纸张、雪地、水面的反光，或另一盏场景里的灯。写不出来源的“补光”不写。

<a id="l05"></a>
## L05 对白场：先定谁亮谁暗

先决定这场戏谁的脸该更清楚、谁该藏在暗里，再安排人物和光源的相对位置，最后从光照表推每一镜受光。窗在甲身后时，拍甲是侧逆光、轮廓亮，反打乙是顺光或前侧光、更清楚；要读清甲的脸，就转机位让窗光变成前侧光，或借场景里已有的台灯，不把窗户搬到甲面前。

<a id="l06"></a>
## L06 视觉中心与光岛

本镜最亮或反差最强的地方必须是视觉中心，不能是无关的灯泡、窗框或白墙；三人以上的画面写明视觉中心是谁。前景偏暗、主体最亮、后景次亮能认出结构，与[coverage K07](coverage.md#k07)三层构图一致。夜景用光岛：场景里已有的灯、窗、火各照一块，人物走进光岛才看清，光岛之间的暗部保留结构，不一律死黑。

<a id="l07"></a>
## L07 冷暖与肤色

场景里同时有不同光源才分冷暖；只有一种光源不硬造冷暖对打。肤色以照在脸上的主光颜色为准，暗面可带一点环境色。

<a id="l08"></a>
## L08 光变

光变必须有看得见的动因（门开光泻进来、车灯扫过、云遮日、灯被关、烛火摇曳），写清节奏和落点。情绪转折只用场景里已有的光源和时间进程（夕阳沉落、蜡烛燃尽），不凭空换照明。光变写明从哪一镜生效，之后的镜头沿用新状态。

<a id="l09"></a>
## L09 材质、眼神光、纵深与色彩

- **材质**：写实皮肤保留毛孔和自然油光，不磨皮；金属、玻璃、水面的反射里只出现场景里有的光源；丝绸有流动高光，粗布吸光，湿衣发暗。
- **眼神光**：来自场景里的窗、灯、火、屏幕，和主光方向一致；低落或被阴影吞没时可以不给，不每镜都写“眼中有光”。
- **纵深主手段**三选一，不叠加：明暗分离；外景远处随距离变淡；已有的柱子、房屋、人群前后重叠、越远越小。不用雾和虚化当万能纵深。
- **可见光束**：场景里同时有介质（雾、烟、尘、蒸汽、雨雪）和具名光源才写，缺一条不写。
- **色彩**：按需要写主色、饱和度、明暗基调、颗粒、高光溢出，写成看得见的描述；同场色调一致，关键转折才让反差色局部短暂出现。软化效果同一镜最多两种（见[C09](camera.md#c09)）。

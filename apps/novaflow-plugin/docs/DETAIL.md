# NovaFlow 账户与原生模型配置

使用浏览器跳转到 NovaFlow 登录并确认授权，连接自动保存到 DeepSeek Harness 官方“设置 → 模型”。在原生页面获取、添加、编辑和删除模型；每个模型的高级设置可配置思考档位，再在对话模型选择器选择实际思考深度。

模型显示原始名称，不追加分组后缀。分组由提供商归属区分。后台同步保留原生模型编辑与删除操作。

插件2.6.1兼容 DSH 0.2.2-rc.2 与 0.2.2-rc.3。Claude系列采用Anthropic Messages，其他文本模型采用OpenAI Responses；识别原始ID及常见vendor前缀，不区分大小写。旧受管配置一次迁移，纯家族原地更新，混合source按家族拆分；原生名称、容量、删除及overrides保留。默认模型自动迁至对应提供商，已有会话引用被拆走模型时需重选。

受管模型统一去掉default／off、默认思考high；首次迁移当前NovaFlow默认选择到high，后续用户选择有效档位会保留。档位优先用官方metadata，缺失时按协议回退，不额外声明adaptive。`migrate_protocols`只迁移旧协议，保留图片与有效自定义档位，同时应用思考规则；可离线保存但不发布缓存桥权限。`configure_models`显式重新启用图片和协议原生档位。普通刷新保留名称、容量、删除等原生编辑并持续规范思考设置。此为2026-11-17尚未发布的本地修复，需加载新代码后核对；实际后端能力仍以平台为准。

账户页通过设备授权读取 `GET /api/novaflow/v1/plugin/usage`，在账户名旁显示个人或公司共享钱包的可用余额。金额单位为元，显示两位小数。企业成员受额度限制时，卡片会显示提示。

登录、账户刷新与默认每10分钟后台刷新后非阻塞读取余额，也可单独“刷新余额”或调用 `refresh_balance`。UI约1.8秒轮询只查询Host状态；读取失败不影响模型登录，保留成功数据并标旧，没有成功数据时不显示假0。退出、拒绝或切换身份清除余额并中止／忽略旧请求。2.6.0历史核验时为AUTH_REQUIRED，真实在线金额仍需用户重新授权后现场验收；本次文档更新未检查2.6.1现场账户。

内置 NovaFlow Image MCP，无需在Magpie配置模型。在「设置 → 模型」选择账户授权的图片和视频模型及对应分组。该服务随登录插件加载，无法单独停用或卸载。长任务返回ID，通过结果工具查询，不自动重复提交。

桌面版社区插件由发行资源一次性初始化，账户功能没有推荐安装流程。模式与首次指引由独立的 @local/novaflow-modes 扩展负责，详情见桌面整合说明。

退出清登录凭据并撤销当前设备，保留原生提供商和模型配置；本机连接地址由插件维护。账户功能属于受保护的客户端核心，不能独立停用或卸载。

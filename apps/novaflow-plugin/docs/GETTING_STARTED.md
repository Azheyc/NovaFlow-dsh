# 安装与快速开始

适用：NovaFlow 插件2.6.1、DSH 0.2.2-rc.2／0.2.2-rc.3。功能与限制见[使用说明](../README.md)，开发与分发流程见[测试与发布](RELEASE.md)。

## 桌面内置账户

NovaFlow 桌面版内置本扩展，账户与余额属于受保护的客户端核心。随客户端更新，不支持单独停用、卸载、更新或编辑插件配置。登录凭据与模型配置在客户端升级时保留；详情见[整合说明](../INTEGRATION.zh.md)。

## 首次使用

1. 打开“账户与余额”，点击“登录 NovaFlow”。
2. 在平台浏览器页面登录并由本人确认设备授权，返回 DSH 等待连接完成。
3. 四个社区插件已随客户端预装，无需登录后安装。新用户可在首次说明弹窗中查看 Agent 预设，或直接关闭继续使用。
4. 到官方“设置 → 模型”查看 NovaFlow 提供商，使用原生获取、添加、编辑、删除与保存功能。模型名不追加分组后缀。
5. 在模型高级设置检查思考档位，在会话底部模型选择器选择实际模型与深度。受管模型去掉default／off，默认high；首次迁移当前NovaFlow默认选择至high，之后主动选择low等有效档位会保留。档位优先用官方metadata，缺失时按协议回退，不额外声明adaptive。配置选项不能保证上游支持对应能力。本地修复需重载插件或重启后核对，详见[模型修复记录](MODEL_405_REPAIR.md)。


账户页负责授权、同步与余额展示，模型编辑在官方模型页进行。2.6.0通过平台New API既有 `plugin/usage` 设备接口显示余额，不需复制Cookie、PAT或后台模型Key，也不需修改后端。

## 查看与刷新余额

登录后查看账户页：主金额为可用余额，另有总额、冻结和更新时间。个人身份显示个人钱包，企业身份显示公司共享钱包；成员日／月限额和剩余额度独立展示，不代表公司总余额。金额已由服务端换算为CNY，null／不限额不显示成0，额度受限会明确提示。

登录、账户刷新和默认每10分钟后台刷新后会非阻塞读取余额，也可点击“刷新余额”单独更新。Agent可用 `novaflow_account` 的 `refresh_balance`；`state`及UI约1.8秒轮询只读Host当前状态，不反复请求平台。读取失败不影响模型登录，无成功数据时不显示假0；已有成功金额保留并标明旧数据及更新时间。退出、拒绝授权或切换身份后旧余额清除。

2.6.0历史核验时为 `AUTH_REQUIRED`；本次文档更新未读取2.6.1现场账户。真实在线金额需用户重新授权后对照平台验收。插件不会为验收自动登录或退出；排查步骤见[余额显示与刷新](TROUBLESHOOTING.md#余额显示与刷新)。

## 图片与视频

图片生成工具省略 model 时使用 NovaFlow 的 `gpt-image-2.6`，无需打开 Magpie 设置。视频需用户明确指定模型；未指定时先列出可用模型再选择。同名模型跨组时还需明确 group。

生成返回作业 ID 后继续查询原作业，不重复提交。默认产物在 DSH 默认工作目录的 `generated-images/` 或 `generated-videos/`。结果未知可能已计费，先检查平台历史。

内置 MCP 使用名称 `magpie-image`。如果与旧客户端冲突，或仍显示旧 Magpie 选模型说明，按[故障排查](TROUBLESHOOTING.md)核对有效预设及实际工具来源。

## 退出与故障处理

账户页退出会清本机登录并尝试撤销当前设备，保留原生提供商和模型配置。撤销失败时按提示到平台“安全与访问”处理。退出不等于退出浏览器，也不撤销其他设备。

Windows 提示缺包管理器时优先修复完整官方 Desktop 自带运行时；不要先要求用户安装全局 pnpm。其他故障从[故障排查](TROUBLESHOOTING.md)中的状态、错误码和当前分发版本开始定位。
